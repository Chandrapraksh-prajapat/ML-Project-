# Google Play Store Feature Engineering

## Project Overview
This is my Machine Learning assignment on Data Preprocessing and Feature Engineering using the Google play store dataset.
## Dataset
- Google Play Store Apps Dataset

- Handling Missing Values

- Feature Engineering
- Data Transformation
- Preparing Data for Machine Learning

- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
